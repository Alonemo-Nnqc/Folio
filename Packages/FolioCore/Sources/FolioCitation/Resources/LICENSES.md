# Third-party resources

This directory bundles the following third-party files used by `FolioCitation`
to render citations with citeproc-js. None of these files are modified from
upstream; they are vendored as-is.

## `citeproc_commonjs.js`

- Source: npm package [`citeproc@2.4.63`](https://registry.npmjs.org/citeproc/-/citeproc-2.4.63.tgz)
  (file `citeproc_commonjs.js` from the package tarball).
- Project: [citeproc-js](https://github.com/Juris-M/citeproc-js) by Frank Bennett.
- License: dual-licensed, CPAL-1.0 OR AGPL-3.0 (see `citeproc-LICENSE.txt` in
  this directory, copied verbatim from the npm package).

## `apa.csl`

- Source: <https://raw.githubusercontent.com/citation-style-language/styles/master/apa.csl>
- Project: [CSL styles repository](https://github.com/citation-style-language/styles).
- License: [CC BY-SA 3.0](https://creativecommons.org/licenses/by-sa/3.0/).

## `china-national-standard-gb-t-7714-2015-numeric.csl`

- Source: <https://raw.githubusercontent.com/citation-style-language/styles/master/china-national-standard-gb-t-7714-2015-numeric.csl>
- Project: [CSL styles repository](https://github.com/citation-style-language/styles).
- License: [CC BY-SA 3.0](https://creativecommons.org/licenses/by-sa/3.0/).

## `locales-en-US.xml` / `locales-zh-CN.xml`

- Source: <https://raw.githubusercontent.com/citation-style-language/locales/master/locales-en-US.xml>
  and `locales-zh-CN.xml` from the same repository.
- Project: [CSL locales repository](https://github.com/citation-style-language/locales).
