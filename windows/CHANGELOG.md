# Folio for Windows 更新日志

格式参照 [Keep a Changelog](https://keepachangelog.com/zh-CN/1.1.0/)，版本号遵循 [语义化版本](https://semver.org/lang/zh-CN/)。
Windows 版的版本号与 macOS 版相互独立，发布时推送 `win-v<版本号>` 标签（例如 `win-v1.0.0`），
`.github/workflows/release-windows.yml` 会把对应小节作为发布说明。

## [Unreleased]

### 变更

- 界面改用 WebView2 + React 重写（核心逻辑不变），布局、尺寸和交互与 macOS 版对齐：全高的侧栏和检查器、圆形工具栏按钮、工具栏下方的标签页、灰色圆角选中行、与 macOS 版相同的设置窗口、标注工具栏和欢迎向导；窗口按钮、Snap Layouts、资源管理器和文件对话框仍是 Windows 自己的
- 新增欢迎向导（Zotero、浏览器插件、智能体、翻译）和主菜单（对应 macOS 版的菜单栏）
- 启动预编译（ReadyToRun），不再依赖 Windows App SDK
- 关闭窗口后 Folio 留在通知区域继续运行（翻译也不中断），从托盘图标或菜单中“退出 Folio”才会彻底退出；托盘菜单使用 Windows 原生样式
- 侧栏、检查器和阅读器面板的显示与隐藏带有过渡动画，切换按钮固定不动；列表的列宽按 macOS 的方式调整，分隔线跟随鼠标
- 图标重新绘制，在桌面和任务栏上更大更清楚
- 阅读器标签页总会写出译文的翻译服务
- 翻译设置的模型下拉框列出服务提供的全部模型；codex 使用自定义服务商（如 CC Switch 配置的中转）时直接向服务商查询模型

### 修复

- 阅读器：打开 PDF 不再崩溃，页面能正常显示（标签页内容设置错误、pdf.js 容器类型错误、论文文件请求失败）
- 窗口与设置窗口按屏幕缩放比例计算大小；记住最大化状态，不再恢复到屏幕外
- 深色模式切换后全部界面立即更新，标题栏按钮颜色跟随
- 鼠标悬停时不再弹出“Ctrl+F”提示；列表和侧栏刷新时不再跳回顶部、丢失选择；标题过长时显示省略号，各列填满窗口
- 从文件夹拖入 PDF 现在可在文献库任意位置松开；跨磁盘移动文献库不再失败
- 标注文字保留单词间的空格，中文作者名可正确读取
- 本机智能体（pi、DeepSeek Harness 等）的长提示词不再因 cmd.exe 的命令行长度限制而反复失败，翻译快得多；DeepSeek Harness 使用其模型页保存的 API Key
- 翻译某一批失败时显示真正的原因，而不是“已取消”；codex 的服务商地址有误时直接说明，不再长时间重试
- 安装或卸载智能体后，翻译服务列表无需重启即可更新

### 分发

- 新的安装向导（Inno Setup）：可选择安装位置和桌面快捷方式，安装前自动关闭正在运行的 Folio，旧的一键安装版会被替换；文献库和设置不受影响。应用内更新照旧
- 安装程序在缺少 WebView2 运行时的电脑上会自动安装
- 安装目录附带 `LICENSE.txt` 和第三方许可声明 `THIRD-PARTY-NOTICES.md`

### 安全

- 来自 PDF、文献元数据或网页的链接只会以网页或邮件链接打开，不再交给 Windows 当作程序或系统协议运行；附件中的可执行文件不会被直接运行
- 只有 Folio 自己的页面能调用宿主接口；阅读器内的页面不能被导航到别处

### 新增（与 macOS 版一致）

- 阅读器：选中或右键标注可改色、加评论、移动、删除，支持撤销/重做；选中文字的右键菜单（拷贝、拷贝为引用、高亮、添加到笔记）；
  查找结果列表、目录折叠、前进/后退、前往页面、打印、边栏宽度可调、Ctrl+滚轮缩放，以及 macOS 版对应的键盘快捷键
- 翻译菜单（翻译全文、对照阅读、取消翻译），翻译进行中可对照阅读已完成的页面
- 设置按 macOS 版重新分组：通用、阅读、文献库、检索、翻译、浏览器、AI
- 列表右键菜单与 macOS 版相同（打开方式、评分、编辑/导出笔记等），搜索时可选范围和 PDF 全文
- 检查器：标注可搜索并按文件分组，摘要可折叠，显示添加与修改时间

### 界面打磨

- 标题栏重做：标签页等宽、圆角、垂直居中，上方不再有多余留白；图标加大；设置、边栏和检查器按钮与 Windows 的最小化、关闭按钮同宽同高
- 侧栏：文献库、分组、标签都有“+”新建按钮，点击分区标题可折叠，图标与文字对齐，选中和悬停样式统一
- 工具栏按钮统一为同一尺寸，信息/标注/笔记、阅读状态和阅读器边栏改用分段控件，列表选中行与 macOS 版一样是灰色
- 窗口变窄时搜索框先收缩，最小窗口尺寸调整为不会挤压内容
- 设置按钮移到左上角；边栏和检查器按钮的箭头指向面板将要移动的方向
- 新建分组时可以选择颜色；深色模式改为中性黑；通用设置中可以调节界面透明度
- 阅读器：添加、修改标注不再刷新页面，相邻行高亮不再重叠，选中文字时单词之间没有空隙，打开论文更快

### 修复（界面打磨后）

- 拖入文件后“松开以添加文件”不消失；底部消息不会自动关闭，现在到时自动消失，也可以手动关闭
- 元数据检索：网络较慢时超时太短，常被误判为失败；放宽了等待时间，失败后会自动重试几次
- 选中文字只显示一个连贯的选中框：pdf.js 自带的选中绘制与 Folio 的重复了；`[`、`6`、`a` 这类窄字符被误判成竖排文字，造成凸块和整行空洞，新加的高亮也不再受影响
- 阅读器支持触控板和触屏双指捏合缩放（此前触控板手势被 WebView2 设置拦截，到不了页面），慢速捏合不会丢失，捏合时界面本身不会被放大；缩放后选中的文字保持选中；Ctrl+滚轮每格的缩放幅度调小
- 整篇翻译时可能闪退：字体内存被垃圾回收后 HarfBuzz 还在读取，随机发作，所有架构都受影响
- 列表行不再显示黑色的键盘焦点框
- 阅读器拖拽：从页面空白处拖动可以直接移动页面（中键在任何位置都可以），拖选文字靠近窗口边缘时页面自动跟随滚动；拖过页面之间的空隙时选区不再翻转到文档开头
- 翻译（本机智能体）：能读到 PowerShell 配置文件里设置的 Key、代理和 PATH，与终端里一致；能找到 nvm、fnm、scoop、pip 等安装的命令；首次启动慢的命令不再被判定为未安装
- 翻译（本机智能体）：入口脚本没有扩展名的 npm 包（Cline、Factory Droid）可以启动了；Gemini CLI 不再因“目录不受信任”失败
- 翻译（自定义命令）：命令里带引号时不再传错
- 标签页改用论文短标题命名，翻译版本把类型放在最前（如“译文 · SnakeSAM”），同一篇有多份同类翻译时只显示有区别的服务、模型或时间；悬停显示完整标题、作者年份和文件
- 列表：切换分组、展开条目不再有逐行刷新和入场动画，几千条文献也是瞬间显示；聚焦某一行不再让各列左右微移；
  拖动手动排序时显示插入线；拖到资源管理器是复制，不会移走库里的文件；拖到某一行不再误把文件附加给它，回收站里不接受拖入
- 导入已在文献库中的论文时，询问是否作为附件的对话框没有出现，只提示一条内容为空的“无法创建条目”
- 对话框标题过长（含论文全名）时被截断，现在完整换行；对话框关闭后焦点回到列表或论文，不再落在第一个按钮上
- 滚动阅读不再触发全库刷新；其他程序（folio-cli）对文献库的修改能被及时发现；重命名后已打开的论文继续跟随新文件名
- 备注、标识符中的换行不再被当作内容变化或拆分失败；隐藏的检查器不再在后台工作；关闭窗口前保存未写入的笔记
- 文献库路径无效时启动不再崩溃，提示后打开默认文献库；后台任务的错误不再被吞掉，加载圈不会一直转
- 高亮只在文字范围内响应点击，不再按外接矩形误选；链接不再显示焦点框和悬停色
- 英文界面：列表分隔符不再用中文顿号，独立文件的按钮不再被截断
- 损坏或加密的 PDF 不再被记入崩溃日志

## [1.0.0] - 2026-11-04

首个 Windows 版本，与 macOS 版使用同一套数据格式（文献库文件夹可在两个平台间直接打开）。

- 文献库：两级分组（可自定义颜色）、彩色标签、回收站、全文搜索、阅读状态与星级评分、一个条目多个文件
- 拖入 PDF 自动识别元数据（Zotero 识别服务、Crossref、arXiv、OpenAlex、DBLP、CVF），找不到时可手动匹配
- 内置阅读器：标签页打开论文，高亮、下划线、删除线、便签、文本框、手绘，批注直接写回 PDF，记住阅读位置
- 笔记、引用（GB/T 7714、APA、IEEE 等）与 BibTeX / RIS / CSL JSON 导入导出
- 全文翻译：与 macOS 版同一套自研引擎，按原版面排入译文，公式、图表和链接保持原样，生成纯译文和左右对照两种 PDF；
  支持 Google / Microsoft 免费翻译、Ollama / LM Studio、本机已登录的 Claude Code、Codex、Gemini CLI 等智能体，
  以及 OpenAI、DeepSeek、通义千问、DeepL 等接口；API Key 用 Windows 账户加密保存
- AI 接入：内置 MCP 服务器和 `folio-cli`，在 设置 ▸ AI 中一键为 Claude Code、Codex、Gemini CLI、Cursor、Claude 桌面版等智能体添加 Folio，
  让它们查找、阅读、引用和整理你的文献
- 从 Zotero 导入：分组、标签（含颜色）、PDF 和 pdf2zh 译文一并导入，只读取 Zotero 数据库的副本
- 浏览器插件（Chrome、Edge、Brave、Firefox 等）一键保存到 Folio
- 应用内自动更新
