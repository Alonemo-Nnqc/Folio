# Folio for Windows 更新日志

格式参照 [Keep a Changelog](https://keepachangelog.com/zh-CN/1.1.0/)，版本号遵循 [语义化版本](https://semver.org/lang/zh-CN/)。

`.github/workflows/release.yml` 会把本文件和仓库根目录 `CHANGELOG.md` 中对应的小节合成发布说明。

## [Unreleased]

### 新增
- Markdown 文档（与 macOS 版一致）：添加菜单或列表空白处右键 ▸ 新建 Markdown 文档（Ctrl+Alt+M）在当前分组新建一篇空白的“未命名文档”，条目右键 ▸ 新建 Markdown 附件 给论文挂一篇空白文档。文档在右侧检查器里直接编辑，也可以在标签页中打开；标题跟随第一个标题行，内容可全文搜索，文件存在文献库的 Files 文件夹里，与 macOS 版使用同样的记录。
- 笔记与 Markdown 文档所见即所得：标题、粗体、斜体、代码、链接、引用、列表、任务、代码块、分隔线按渲染后的样子显示，只有正在编辑的行显示 Markdown 符号；任务框点一下即可打勾。
- 文档标签页上方的格式工具栏（标题、粗体、斜体、删除线、行内代码、链接、三种列表、引用、代码块、表格、分隔线），可用标题栏右侧的按钮或 设置 ▸ 通用 ▸ 显示 Markdown 文档工具栏 打开或关闭。
- 条目的笔记直接显示为条目下的“笔记”一行：单击在检查器中编辑，双击在标签页中打开，右键可导出。
- 标签页可以拖出主窗口成为独立窗口（或右键 ▸ 移到新窗口），独立窗口工具栏开头的“放回标签页”按钮把它放回主窗口。
- 条目列表空白处右键：添加文件、通过标识符添加、新建 Markdown 文档、新建分组、新建标签、导入、全选、多选。
- 条目列表新增“出版物”列（默认显示，可排序）：期刊、会议的简称（CVPR、TPAMI、NeurIPS……）以徽标显示，后面跟 CCF 等级、中科院分区、JCR 分区和影响因子；常见会议和期刊的 CCF 等级内置识别，其余指标来自 easyScholar。macOS 版保存的“按出版物排序”在 Windows 上同样生效。
- 自动翻译新添加的论文（设置 ▸ 翻译 ▸ 速度，默认关闭）：导入、浏览器保存或自动下载的 PDF 还没有译文时，用当前服务和设置自动开始翻译；会等元数据检索完成，扫描件先识别文字，已有译文或本身就是译文的不再翻译；服务没有配置好时只提示一次。
- 工具栏新增“多选”按钮：单击条目即可选中或取消（不用按 Ctrl），每行图标变成勾选圆圈，右侧显示批量操作面板（全选、取消选择、完成），按 Esc 或再点一次退出。
- 多选条目批量处理：选中多篇文献时，右侧检查器显示批量操作面板（添加到分组、标签、阅读状态、评分、引用与导出、翻译全文、重新检索元数据、在资源管理器中显示、删除），并列出共同标签（可一键从全部移除）；右键菜单也新增“翻译全文（N 篇）”和“重新检索元数据”。

### 改进
- 同时翻译分成“同一服务同时翻译”（1–4 篇）和“同时翻译总数”（2–8 篇，默认 6）两个限制：用不同服务翻译的论文互不等待；排队中的论文记住加入队列时的服务和选项，之后改设置不影响它们（与 macOS 版一致）。
- 笔记与 Markdown 文档的编辑：回车自动续写列表和引用，空项回车结束列表；Tab / Shift+Tab 调整列表层级；Ctrl+B / Ctrl+I / Ctrl+K 加粗、斜体、插入链接；输入法组字时不自动保存。
- 阅读器左侧栏打开论文时显示上次使用的页面（缩略图、目录或批注）；没有目录的论文显示缩略图，但不改变记住的选择。
- 运行期间每小时、以及回到 Folio 时（距上次检查超过半小时）自动检查更新；侧栏底部的更新提示改为扁平、简洁的样式。
- 标签去掉左侧的颜色圆点，颜色体现在胶囊底色上。
- 设置等界面去掉大部分说明小字，只保留必要的提示，界面更简洁。

### 修复
- 翻译（与 macOS 版一致）：只有竖线和表头横线的表格（如 SAM、BSDS 的结果表）没有被识别为表格，译文错行、错位、字号不一；现在按竖线识别这类表格，跨列表头、分组行单独成格，同一表格的单元格统一字号；表头缩写（med.、freq.）和 small / large 等常用词按固定译法翻译。

## [1.4.0] - 2026-11-16

### 新增
- 术语表管理（设置 ▸ 翻译 ▸ 术语 ▸ 管理…）：模型从论文中提取的术语记入术语表并在之后的翻译中沿用；可按译文语言查看、搜索、修改、停用、删除、手动添加，支持 CSV 导入导出；术语表文件与 macOS 版格式相同（与 macOS 版一致）。
- “显示‘已翻译’标签”开关（设置 ▸ 通用 ▸ 列表，与 macOS 版一致）。
- 翻译前估算用量：“翻译全文”面板显示预计的 tokens 与大致费用（与 macOS 版一致）。

### 改进
- 批注工具与 macOS 版一致重做：点一下切换工具，再点一次（或右键）才弹出颜色与样式菜单，按钮旁不再有小箭头；高亮、下划线、手绘的图标直接显示成当前颜色（深色主题下的黑色、浅色主题下的浅色自动调整以保证看得清）；便签工具换成竖长的便签图标。支持自定义颜色（系统取色器，最近五个在所有工具中可选）。便签点下即贴、同色简洁卡片直接输入、无字也保留；文本框透明输入框、细线框、上方工具条换颜色和字号、清晰显示；各工具的指针与 macOS 版一致。单独的“颜色”按钮和“默认高亮颜色”设置已去掉。
- 批注继续打磨（与 macOS 版一致）：颜色菜单与批注右键菜单只显示颜色圆圈，自定义颜色为彩色圆圈；手绘粗细、橡皮擦大小、文本框字号以圆点、圆圈和字母表示；便签卡片跟随便签滚动缩放、可拖动右下角调整大小；文本框可拖动边框移动（空的也可以），点别处时空文本框自动删除；字号控件改为“小 A / 字号 / 大 A”；手绘时的线条与完成后的笔迹粗细一致、不再闪烁（此前预览细约 25%）；删除线默认黑色。
- 设置整理与 macOS 版一致：“检索”并入“文献库”，“划词翻译”并入“阅读”，“阅读”新增几项批注与阅读位置设置。
- 大模型翻译改为流式请求，长回复不再超时，进度按实际收到的内容前进；排版（小型大写字母、居中图注、表格竖线、公式旁的斜线）与编辑 PDF 文字（词间距、整词同一字体、整段收紧行距）的改进与 macOS 版一致；DeepSeek 默认模型改为 deepseek-flash。
- 文献列表中写过笔记的论文，标题后显示笔记图标（与 macOS 版一致）。
- 默认打开文件：检查器的文件列表和列表中展开的论文里，默认文件带“默认”标记；右键菜单中当前默认文件打勾（与 macOS 版一致）。
- 标签与徽标样式与 macOS 版一致：彩色标签前加色点、去掉描边；“已翻译”“默认”、期刊分区改为小圆角矩形。
- 全文翻译按钮（文献库与阅读器工具栏、右键菜单）换成与 macOS 版相同的新图标，和划词翻译的图标区分开。
- 翻译引擎与 macOS 版同步改进：术语表先于大部分批次、漏译与未翻译段落自动补译、重复文字只翻译一次、被拒绝的附加参数自动去掉重发、输出被截断时直接拆小、能读懂更多回复格式；OpenAI 推理模型默认思考程度改为“低”，Claude、Gemini 默认少思考并能识别内容审核拒绝与截断；Azure OpenAI 使用低温度。

### 修复
- 手绘划出页面边缘时，页面外的部分不再保存（与 macOS 版一致）。
- 橡皮擦不再留下肉眼几乎看不见的碎屑（短于线宽 1.5 倍的碎段一并擦掉，与 macOS 版一致）。
- 用 CodeBuddy 翻译极慢（与 macOS 版一致）：设置页标出已失效的模型并可一键改用可用模型，翻译开始时如模型已失效立即在翻译面板说明改用了哪个模型，一批超过 90 秒没有返回时说明原因与办法；最快模型的顺序按真实批次重测；翻译日志写明实际使用的模型和同时请求数。
- **翻译后部分文字变白、大量文字消失**（与 macOS 版一致）：按 PDF 的色彩空间（Separation/DeviceN 及其转换函数、Indexed、ICC、Lab）读取文字颜色，不再把专色“满墨”读成白色；落在白纸上的近白色文字一律以黑色绘制。
- 橡皮擦擦掉的手绘重新打开后又出现在批注列表里：写入文件的改为页面上实际显示的擦除结果，两者不再有出入。
- 服务返回空译文时不再写入缓存。

### 维护
- 清理未被引用的代码。

## [1.3.0] - 2026-11-13

### 新增
- “已翻译”标签：已有译文的文献，在列表标题后显示绿色的“已翻译”标签，悬停可查看有哪些译文；翻译进行中暂时隐藏（与 macOS 版一致，#15）。
- 编辑 PDF 文字、扫描件识别文字（使用 Windows 自带 OCR，需安装中文或英文的“光学字符识别”语言功能）、期刊分区与影响因子、阅读器橡皮擦、四级分组（与 macOS 版一致）。
- 翻译图片中的文字（设置 ▸ 翻译，可开关）：用 Windows 自带的 OCR 识别插图里的文字，在原位置换成译文，图片其余部分不变；矢量插图的标注与侧向文字也会翻译，并保持原有的对齐与对称（与 macOS 版一致）。
- CodeBuddy（WorkBuddy）翻译服务（官方图标）：检测到 WorkBuddy 桌面版时可一键安装 CodeBuddy 命令行，装好后自动打开命令行窗口登录，只在未登录时提示登录；模型列表与账号一致，默认自动选用快速模型（与 macOS 版一致）。
- 翻译图片中的文字：论文语言（例如英文）的 Windows 文字识别未安装时，设置中会提示并可一键安装（需管理员确认）；用中文识别读英文会把小字、斜体读错。

### 改进
- 使用文档：设置 ▸ 通用 ▸ 帮助 新增“Folio 使用文档”，打开产品主页上的使用指南，完整介绍全部功能、设置项、翻译服务配置、快捷键与常见问题。
- 新版本提示改为边栏左下角的小卡片，不再占用工具栏。
- 翻译更快、出错即时提示具体原因，思考程度选择修复（与 macOS 版一致）；图片文字分块并行识别。
- 翻译图片中的文字大幅改进（与 macOS 版一致）：图片按区域高分辨率渲染并分块识别，小字不再读错、漏读；图标保留在原处；乱码不再翻译；跨行标注整句翻译后按词分行；结合标题、摘要、术语表和图注翻译专业名词；字号按原文测量并统一，保持居中、对齐与对称，落在原文基线上。
- “翻译全文”面板改用与设置页相同的样式，并加入“翻译表格”“翻译图片中的文字”“翻译参考文献”开关。
- 智能体翻译更快：同时 8 个请求、Codex 精简启动项、不可恢复的错误不再重试。
- 浏览器插件：“安装”与新的“显示插件文件夹”会在资源管理器中选中插件文件夹，打开扩展页面的开发者模式后直接拖入即可。
- 划词翻译：预先连接与令牌续取，Google、微软免费翻译明显更快；小窗可拖动。

### 修复
- 翻译输出中的图片不再被压成低质量 JPEG。
- 编辑 PDF 文字改为原位编辑（与 macOS 版一致），进入编辑模式不再弹出提示条：改一个字或删一个标点只重排受影响的行，沿用原文字体与排版，不再整段换成另一种字体；保存时只给该页追加一次更新，批注与链接原样保留，页面只重绘被修改的那一页，不再整份文件刷新；撤销即还原文件。
- 浏览器插件“安装…”：新版 Edge 会忽略从命令行打开的 edge://extensions 而只打开新标签页，现在同时拷贝扩展页面的地址并提示粘贴到地址栏。
- 阅读页面右键菜单在点击空白处后不关闭、必须点选某一项的问题；批注编辑框、划词翻译小窗、快速预览同样会在点外面、按 Esc 或窗口失去焦点时关闭。

## [1.1.0] - 2026-11-07

首个 Windows 版本，与 macOS 版功能、界面一一对应，并使用同一套数据格式：同一个文献库文件夹（例如放在同步盘中）在两个平台上都能直接打开。

### 文献管理

- 两级分组（可自定义颜色）、彩色标签、回收站、全文搜索、阅读状态与星级评分、一个条目多个文件
- 拖入 PDF 自动识别元数据（Zotero 识别服务、Crossref、arXiv、OpenAlex、DBLP、CVF），找不到时可手动匹配
- 笔记、引用（GB/T 7714、APA、IEEE 等）与 BibTeX / RIS / CSL JSON 导入导出
- 从 Zotero 导入：分组、标签（含颜色）、PDF 和 pdf2zh 译文一并导入，只读取 Zotero 数据库的副本

### 阅读

- 标签页打开论文，高亮、下划线、删除线、便签、文本框、手绘，批注直接写回 PDF，记住阅读位置
- 对照阅读：原文与译文左右并排，翻译进行中即可阅读已完成的页面
- 触控板捏合与 Ctrl+滚轮缩放、查找、目录、缩略图、打印

### 翻译

- 与 macOS 版同一套自研引擎，按原版面排入译文，公式、图表和链接保持原样，生成纯译文和左右对照两种 PDF
- 支持 Google / Microsoft 免费翻译、Ollama / LM Studio、OpenAI、DeepSeek、通义千问、DeepL 等接口，以及本机已登录的 Claude Code、Codex、Gemini CLI、pi、DeepSeek Harness 等智能体；API Key 用 Windows 账户加密保存

### AI 与浏览器

- 内置 MCP 服务器和 `folio-cli`，在 设置 ▸ AI 中一键为 Claude Code、Codex、Gemini CLI、Cursor、Claude 桌面版等智能体添加 Folio
- 浏览器插件（Chrome、Edge、Brave、Firefox 等）一键保存到 Folio，在 设置 ▸ 浏览器 中安装

### Windows

- 窗口按钮、Snap Layouts、资源管理器、文件对话框和 Ctrl 快捷键都是 Windows 自己的
- 关闭窗口后 Folio 留在通知区域继续运行（翻译不中断），从托盘菜单“退出 Folio”才会彻底退出
- 安装向导可选择安装位置和桌面快捷方式，不需要管理员权限；缺少 WebView2 运行时的电脑会自动安装
- 应用内自动更新：下载新的安装程序，校验后在重新启动或退出时静默安装
- 支持 x64 和 ARM64
