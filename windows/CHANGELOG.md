## [Unreleased]

### 新增
- 编辑 PDF 文字、扫描件识别文字（使用 Windows 自带 OCR，需安装中文或英文的“光学字符识别”语言功能）、期刊分区与影响因子、阅读器橡皮擦、四级分组（与 macOS 版一致）。
- 翻译图片中的文字（设置 ▸ 翻译，可开关）：用 Windows 自带的 OCR 识别插图里的文字，在原位置换成译文，图片其余部分不变；矢量插图的标注与侧向文字也会翻译，并保持原有的对齐与对称（与 macOS 版一致）。
- CodeBuddy（WorkBuddy）翻译服务（官方图标）：检测到 WorkBuddy 桌面版时可一键安装 CodeBuddy 命令行，装好后自动打开命令行窗口登录，只在未登录时提示登录；模型列表与账号一致，默认自动选用快速模型（与 macOS 版一致）。
- 翻译图片中的文字：论文语言（例如英文）的 Windows 文字识别未安装时，设置中会提示并可一键安装（需管理员确认）；用中文识别读英文会把小字、斜体读错。

### 改进
- 使用文档：设置 ▸ 通用 ▸ 帮助 新增“Folio 使用文档”，打开产品主页上的使用指南，完整介绍全部功能、设置项、翻译服务配置、快捷键与常见问题。
- 新版本提示改为边栏左下角的小卡片，不再占用工具栏。
- 翻译更快、出错即时提示具体原因，思考程度选择修复（与 macOS 版一致）；图片文字分块并行识别。
- 翻译图片中的文字大幅改进（与 macOS 版一致）：图片按区域高分辨率渲染并分块识别，小字不再读错、漏读；图标保留在原处；乱码不再翻译；跨行标注整句翻译后按词分行；结合标题、摘要、术语表和图注翻译专业名词；字号按原文测量并统一，保持居中、对齐与对称，落在原文基线上。
- “翻译全文”面板改用与设置页相同的样式，并加入“翻译表格”“翻译图片中的文字”“翻译参考文献”开关。
- 智能体翻译更快：同时 8 个请求、Codex 精简启动项、不可恢复的错误不再重试。
- 浏览器插件：“安装”与新的“显示插件文件夹”会在资源管理器中选中插件文件夹，打开扩展页面的开发者模式后直接拖入即可。
- 划词翻译：预先连接与令牌续取，Google、微软免费翻译明显更快；小窗可拖动。

### 修复
- 翻译输出中的图片不再被压成低质量 JPEG。
- 编辑 PDF 文字改为原位编辑（与 macOS 版一致），进入编辑模式不再弹出提示条：改一个字或删一个标点只重排受影响的行，沿用原文字体与排版，不再整段换成另一种字体；保存时只给该页追加一次更新，批注与链接原样保留，页面只重绘被修改的那一页，不再整份文件刷新；撤销即还原文件。
- 浏览器插件“安装…”：新版 Edge 会忽略从命令行打开的 edge://extensions 而只打开新标签页，现在同时拷贝扩展页面的地址并提示粘贴到地址栏。
- 阅读页面右键菜单在点击空白处后不关闭、必须点选某一项的问题；批注编辑框、划词翻译小窗、快速预览同样会在点外面、按 Esc 或窗口失去焦点时关闭。

- 设置 ▸ AI 新增 Pi、Grok CLI、Hermes Agent、OpenClaw、Kimi Code、Droid、Amp、goose、DeepSeek Harness 的检测与配置。

### 变更
- 设置按钮移到侧栏左下角；AI 设置页使用官方智能体图标；对话框打开时窗口按钮颜色与页面一致；翻译服务列表隐藏未安装的智能体；选中文字后切换标注工具直接标注。

## [1.1.0] - 2026-11-07

首个 Windows 版本，与 macOS 版功能、界面一一对应，并使用同一套数据格式：同一个文献库文件夹（例如放在同步盘中）在两个平台上都能直接打开。

### 文献管理

- 两级分组（可自定义颜色）、彩色标签、回收站、全文搜索、阅读状态与星级评分、一个条目多个文件
- 拖入 PDF 自动识别元数据（Zotero 识别服务、Crossref、arXiv、OpenAlex、DBLP、CVF），找不到时可手动匹配
- 笔记、引用（GB/T 7714、APA、IEEE 等）与 BibTeX / RIS / CSL JSON 导入导出
- 从 Zotero 导入：分组、标签（含颜色）、PDF 和 pdf2zh 译文一并导入，只读取 Zotero 数据库的副本

### 阅读

- 标签页打开论文，高亮、下划线、删除线、便签、文本框、手绘，批注直接写回 PDF，记住阅读位置
- 对照阅读：原文与译文左右并排，翻译进行中即可阅读已完成的页面
- 触控板捏合与 Ctrl+滚轮缩放、查找、目录、缩略图、打印

### 翻译

- 与 macOS 版同一套自研引擎，按原版面排入译文，公式、图表和链接保持原样，生成纯译文和左右对照两种 PDF
- 支持 Google / Microsoft 免费翻译、Ollama / LM Studio、OpenAI、DeepSeek、通义千问、DeepL 等接口，以及本机已登录的 Claude Code、Codex、Gemini CLI、pi、DeepSeek Harness 等智能体；API Key 用 Windows 账户加密保存

### AI 与浏览器

- 内置 MCP 服务器和 `folio-cli`，在 设置 ▸ AI 中一键为 Claude Code、Codex、Gemini CLI、Cursor、Claude 桌面版等智能体添加 Folio
- 浏览器插件（Chrome、Edge、Brave、Firefox 等）一键保存到 Folio，在 设置 ▸ 浏览器 中安装

### Windows

- 窗口按钮、Snap Layouts、资源管理器、文件对话框和 Ctrl 快捷键都是 Windows 自己的
- 关闭窗口后 Folio 留在通知区域继续运行（翻译不中断），从托盘菜单“退出 Folio”才会彻底退出
- 安装向导可选择安装位置和桌面快捷方式，不需要管理员权限；缺少 WebView2 运行时的电脑会自动安装
- 应用内自动更新：下载新的安装程序，校验后在重新启动或退出时静默安装
- 支持 x64 和 ARM64
