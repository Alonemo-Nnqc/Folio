# Third-party resources

This directory bundles the following third-party files used by `FolioCitation`
to render citations with citeproc-js. None of these files are modified from
upstream; they are vendored as-is.

## `citeproc_commonjs.js`

- Source: npm package [`citeproc@2.4.63`](https://registry.npmjs.org/citeproc/-/citeproc-2.4.63.tgz)
  (file `citeproc_commonjs.js` from the package tarball).
- Project: [citeproc-js](https://github.com/Juris-M/citeproc-js) by Frank Bennett.
- License: dual-licensed, CPAL-1.0 OR AGPL-3.0 (see `citeproc-LICENSE.txt` in
  this directory, copied verbatim from the npm package).
