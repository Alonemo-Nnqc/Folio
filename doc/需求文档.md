## 1. 产品定位

- 替代 Zotero 的日常文献管理：导入 PDF → 自动识别元数据 → 分组/标签整理 → 快速找到并打开。
- 轻量：常驻内存目标 < 150 MB，冷启动 < 1 秒。
- 原生：AppKit 骨架 + SwiftUI（检查器、设置、弹窗），系统 Liquid Glass 材质，遵循 HIG，中文界面，深浅色跟随系统。
- 【v2.0 变更】内置 PDF 阅读器：用苹果 PDFKit（与"预览"同一渲染引擎）在 Folio 的标签页中阅读和批注，批注以标准格式写回 PDF，与"预览"互通。仍可选择用"预览"或其他 App 打开。

## 2. 运行环境

- macOS 26 及以上（Liquid Glass 需要），Apple Silicon 与 Intel 均可运行。
- 使用用户的 Apple 个人开发者证书（Team `2WJC7GTSV4`）签名构建。
- 元数据检索需要联网；离线时其余功能都能正常使用。

## 3. 术语

| 术语 | 含义 |
| --- | --- |
| 条目 | 一篇文献的记录，带有元数据（标题、作者、年份、来源等），下面挂 0 到多个文件 |
| 文件 | 条目下的附件（PDF 或其他类型文件） |
| 独立文件 | 没有匹配到元数据、不属于任何条目、直接出现在列表顶层的文件 |
| 顶层行 | 列表中的一行：条目或独立文件 |
| 内置分组 | 所有文献、未分组、回收站 |
| 自建分组 | 用户创建的分组，最多两级（一级分组、子分组） |
| 视图 | 中间列表当前显示的内容：某个内置分组、某个自建分组或某个标签 |

## 4. 功能需求

### 4.1 条目列表（中间栏）

- **LIST-01【原始】** 列表以行显示顶层行（条目与独立文件）。
- **LIST-02【原始】** 列可自定义：右键列头勾选显示或隐藏列，拖动列头调整顺序，拖动列边界调整宽度，配置自动保存。
  - 可选列：标题、作者、年份、来源、标签、类型、添加日期、修改日期、DOI、出版社、卷、期、页码、阅读状态、评分、文件数、引用键。
  - 默认显示：标题、来源、作者、年份、标签、添加日期。
  - 【细化】"标题"列承载展开箭头，始终显示、不可隐藏，但可以调整位置和宽度。
- **LIST-03【原始】** 条目左侧有展开箭头：折叠时朝右，点击后朝下（系统动画）并展开该条目下所有文件；再次点击折叠。
  - 【细化】没有文件的条目、独立文件不显示箭头。键盘 → / ← 也可展开或折叠。展开状态在会话内按条目记忆，切换视图后保留。
- **LIST-04【细化】** 作者列格式：1 位作者显示"Zhang, Tengya"；2 位显示"Lou, Meng & Yu, Yizhou"；3 位及以上显示"Zhang, Tengya et al."。
- **LIST-05【细化】** 空值显示"—"；过长文字尾部省略。
- **LIST-06【细化】** 排序：
  - 每个视图默认按"自定义顺序"排列，新条目排在最前。
  - 点击列头按该列升序或降序排序。
  - "显示"菜单提供"按自定义顺序排列"。
  - 每个视图各自记忆自己的排序方式和自定义顺序。
  - 按列排序时拖拽调整顺序，会以当前显示顺序为基础自动切换为自定义顺序。
- **LIST-07【细化】** 支持 ⌘ / ⇧ 多选，右键菜单与拖拽都支持批量操作。
- **LIST-08【原始】** 双击条目，用设置中的打开方式打开该条目的默认打开文件。
  - 【细化】双击文件行打开该文件；双击独立文件打开它自己；条目没有文件时打开其 DOI / URL 页面（若有）。回车键等同双击。
- **LIST-09【确认】** 按空格键用 Quick Look 预览选中条目的默认文件或选中的文件。
- **LIST-10【v2.7，v2.8 变更】** 选中行为灰色半透明的液态玻璃样式（上亮下暗的灰色玻璃体、顶部高光边与细边线；列表有焦点时略深），不再使用强调色；文字、图标和标签保持原色；"默认""译文"与标签胶囊的文字光学居中。
- **LIST-10【细化】** 视图为空时显示引导文字"拖入 PDF 或点击 + 添加文献"。
- **LIST-11【细化】** 条目右键菜单（自建分组视图中）：
  - 打开、快速查看
  - 添加到 ▸、标签 ▸、阅读状态 ▸、评分 ▸、复制引用 ▸
  - 添加文件…、重新检索元数据、在 Finder 中显示
  - 从当前分组移除、删除
  - 其他视图中没有"从当前分组移除"。回收站中只有"恢复""彻底删除"。
- **LIST-12【原始】** "添加到 ▸"子菜单列出所有自建分组（子分组缩进显示），不含当前分组。已包含该条目的分组前显示勾号；选择这类分组时提示"「分组名」中已有该条目"。

### 4.2 文件与默认打开文件

- **FILE-01【原始】** 一个条目可包含多个文件，展开后以缩进子行显示：文件类型图标、文件名。
- **FILE-02【原始】** 每个有文件的条目恰好有一个默认打开文件。条目创建时，默认打开文件是第一个添加的文件。
- **FILE-03【原始】** 展开后，默认打开文件那一行显示"默认"胶囊标识。
- **FILE-04【原始】** 文件右键菜单：打开、快速查看、**设为默认打开文件**（已是默认时显示勾号且不可点）、在 Finder 中显示、删除。
- **FILE-05【细化】** 默认打开文件被删除后，自动改为剩余文件中最早添加的那个；之后恢复原文件时，不会自动恢复它的默认身份。
- **FILE-06【补充】** 条目右键"添加文件…"：选择文件追加到该条目下。
  - 追加的文件同样复制进文献库并按规则命名，不触发元数据检索。
  - 与库中已有文件内容完全相同时，提示"已有该文献"，不追加。
- **FILE-07【细化】** 任意类型的文件都可以作为附件；只有 PDF 会触发元数据检索、全文索引和标注读取。
- **FILE-08【细化】** 文件被外部 App 修改后（例如在"预览"中加了批注），Folio 自动更新该文件的指纹、全文索引和标注显示。

### 4.3 元数据检索引擎

- **META-01【原始】** 添加 PDF 后，它立即以独立文件行出现在列表中，行首图标换成旋转的进度指示，并显示"正在检索元数据…"，后台自动检索。
- **META-02【细化】** 检索流程，多个数据源并行，先返回的可信结果即采用：
  0. 【v2.0】同时把前 5 页的文字版面（单词位置、字号、粗斜体，与 Zotero pdf-worker 的格式相同）发给 Zotero 识别服务（`services.zotero.org/recognizer/recognize`）。返回 arXiv ID / DOI / ISBN 时按标识符查询完整元数据；只返回标题、作者等字段时，在首页核对标题后直接采用。该服务不可用时自动退回下面的开放数据源流程，不影响使用。
  1. 读取 PDF 内嵌元数据和 XMP，从前两页文本和文件名中提取 DOI、arXiv ID。
  2. 有标识符时，通过 Crossref / DOI 内容协商 / arXiv 查询元数据，并校验返回的标题确实出现在 PDF 首页（防止误取参考文献里的 DOI）。
  3. 没有标识符时，从首页提取标题（字号最大的文本行），并行查询 Crossref、OpenAlex、DBLP、arXiv。按标题相似度加上"作者姓名是否出现在首页"打分，超过阈值才采纳。
  4. 【细化 v1.3】首页带 CVF 开放获取水印的 PDF（CVPR / ICCV / WACV），同时直接查询 CVF 网站上该论文的页面，取官方 BibTeX 和摘要。如果 CVF 网站上没有这篇（例如 workshop 论文），而 PDF 自带的标题和作者都能在首页核对到，就用 PDF 自带的元数据。
  5. 数据源只覆盖英文开放数据源，不支持知网、万方【确认】。
- **META-03【原始】** 检索成功：
  - 独立文件变成条目，该文件成为条目的第一个文件，也是默认打开文件，并按命名规则重命名。
  - 写入的字段：类型、标题、作者、年份/日期、来源、卷、期、页码、出版社、DOI、arXiv ID、ISBN、URL、摘要。
- **META-04【原始】** 检索失败（没有可信匹配）：保留原文件不变，不创建条目，进度指示消失，显示轻提示（多个失败合并为一条）。
- **META-05【细化】** 因网络错误失败的，网络恢复后自动重试，最多 3 次。检索引擎升级（新增数据源）后首次启动时，此前检索失败的 PDF 会自动再检索一次。
- **META-06【原始】** 性能：网络正常时，检索耗时中位数 ≤ 3 秒，90% 的论文 ≤ 5 秒；单个文件总超时 15 秒；批量导入时最多 4 个文件并行检索。
- **META-07【补充】** 独立文件右键菜单：
  - "重新检索元数据"
  - "手动匹配…"：输入 DOI、arXiv ID 或标题搜索，从结果列表中选一项创建条目
- **META-08【补充】** 条目右键"重新检索元数据"：用条目已有的 DOI / arXiv ID / 标题重新获取并覆盖元数据字段；标签、分组、评分、阅读状态、文件都保持不变。
- **META-09【补充】** 工具栏"+"菜单里的"通过标识符添加…"：输入 DOI、arXiv ID 或 ISBN，创建一个没有文件的条目（之后可以追加文件）。

### 4.4 重复检测

- **DUP-01【确认】** 文件级重复：新文件与库中未删除的文件内容完全相同（SHA-256）时：
  - 不导入，提示"已有该文献「标题」"。
  - 如果是在自建分组中导入，且已有条目不在该分组，就把已有条目加入该分组，提示"已有该文献，已加入「分组名」"。
- **DUP-02【细化】** 内容相同的文件在回收站中时，弹窗"回收站中已有该文献，是否恢复？"，选项为［恢复］［取消］。
- **DUP-03【确认】** 条目级重复：检索成功后，若库中已有相同条目——DOI 相同；或没有 DOI 时，标准化标题、年份、第一作者姓都相同——弹窗"已有该条目「标题」"：
  - 选项为［作为附件添加到该条目］［放弃］。选"放弃"会删掉刚导入的副本。
  - 同一批里有多个重复时，提供"对其余项执行相同操作"复选框。
  - 如果是在自建分组中导入，已有条目会顺带加入该分组。
- **DUP-04【细化】** 通过标识符添加的条目已存在时，提示"已有该条目"并在列表中选中它。
- **DUP-05【原始】** 用"添加到"或拖拽把条目放进某分组时，若该分组已有它，提示"「分组名」中已有该条目"，不重复添加。
- **DUP-06【原始】** 同一条目无论属于多少个分组，在"所有文献"中都只出现一次。

### 4.5 文件存储

- **STORE-01【确认】** 文献库默认位于 `~/Folio`，内含数据库和 `Files` 文件夹。设置中可更改位置，整个文献库会随之迁移。
- **STORE-02【确认】** 导入时复制一份到文献库，原文件不动。
- **STORE-03【确认】** 命名规则：
  - 格式为`第一作者姓_年份_标题.pdf`；标题截断到 80 个字符，非法字符替换掉；同名时追加序号。
  - 以下情况按规则命名：检索成功、重新检索元数据、手动匹配、追加文件。
  - 手动编辑元数据不会触发重命名；独立文件保持原名。
  - 设置中可以关闭自动重命名。
- **STORE-04【原始】** 彻底删除时，文献库中的副本一并删除。

### 4.6 左侧栏与分组

- **SIDE-01【v2.1 变更】** 左侧栏使用系统 Liquid Glass 侧栏（`NSSplitViewItem` 侧栏样式）。系统的"显示/隐藏边栏"按钮位于侧栏的右边缘（快捷键 ⌃⌘S）；侧栏隐藏后自动移到红绿灯右侧。
- **UI-10【v2.3】** 所有选择颜色的地方（标签、分组颜色菜单、批注颜色菜单与工具栏、默认高亮颜色）都直接显示颜色圆点，不只显示颜色名称。
- **SIDE-16【v2.2】** 分组可以自定义图标颜色：分组右键"颜色 ▸"中选择默认（强调色）、10 种预设色或"自定义…"（系统颜色面板）。颜色用于侧栏、"添加到"菜单和检查器中的分组胶囊。
- **SIDE-15【v2.1】** 侧栏是系统源列表：
  - 分为"文献库"（所有文献、未分组、回收站）、"分组"、"标签"三个分区，分区标题悬停时显示系统的"显示/隐藏"和 + 按钮，可折叠，折叠状态会记住。
  - 行高、字号、图标大小跟随 系统设置 ▸ 外观 ▸ 边栏图标大小。
  - 选中项使用系统侧栏的半透明高亮，侧栏不抢键盘焦点（与 Finder 相同）。
  - 双击分组重命名，也可以在右键菜单中重命名；双击分区标题折叠或展开。
- **SIDE-01a【v2.8】** 折叠"分组"分区或父分组时，即使当前选中的分组被收起，列表仍保持该分组的内容，不跳到"所有文献"；展开后重新高亮该分组。点击侧栏空白处不会取消选中。
- **SIDE-02【v2.1 变更】** 搜索框移到工具栏（系统搜索框，见 4.9）。"新建分组"放在"分组"分区标题的 + 按钮（悬停显示）、文件菜单（⇧⌘N）和侧栏空白处右键菜单中。
- **SIDE-03【原始】** 内置分组"所有文献""未分组""回收站"：
  - 固定在最上方，顺序固定。
  - 不可删除、重命名或拖动；其他分组不能拖到它们之间或上方。
  - 内置分组与自建分组之间有一条美观的分隔线。
- **SIDE-04【细化】** 每个分组右侧显示条目数量；回收站显示其中的项目数。
- **SIDE-05【v2.1 变更】** 自建分组最多两级：
  - 有子分组的分组左侧显示系统展开箭头，点击展开或收起，子分组比父分组缩进。
  - 展开状态持久保存。
- **SIDE-06【原始】** 分组右键菜单：
  - 一级分组：新建子分组、重命名、删除分组。
  - 子分组：重命名、删除分组（没有"新建子分组"）。
  - 回收站：清空回收站（需确认）。
  - "所有文献""未分组"没有右键菜单。
- **SIDE-07【原始】** 在侧栏空白处右键：创建分组、搜索文献。
- **SIDE-08【细化】** 新建分组会插入一个"未命名分组"并立即进入重命名状态。名称不能为空；同级分组不能重名（重名时提示）。
- **SIDE-09【确认】** 删除分组会弹窗确认，说明其中的条目会保留在文库中：
  - 选项为［删除分组］［同时将条目移到回收站］［取消］。
  - 删除一级分组时，其子分组一并删除。
  - 分组本身不进回收站。
- **SIDE-10【细化】** 父分组视图显示自身及其子分组中的全部条目（去重）。设置中可以关闭。
- **SIDE-11【原始】** 侧栏右边界可以左右拖动，连续、平滑；拖到最小宽度以下时自动收起。宽度持久保存。
- **SIDE-12【原始】** 分组拖拽：
  - 把一个分组拖到另一个一级分组上，它就成为该分组的子分组。被拖的分组本身有子分组时不允许，因为会超过两级。
  - 同级分组之间拖动可以调整顺序，拖动时有插入线指示。
  - 【细化】子分组拖到一级分组之间的间隙，会提升为一级分组。
  - 拖到内置分组区域无效。
- **SIDE-13【细化】** "所有文献" = 所有未删除的条目与独立文件；"未分组" = 不属于任何自建分组的未删除条目与独立文件。
- **SIDE-14【补充】** 标签区：分组下方列出所有标签（颜色圆点、名称、数量）。
  - 点击标签，中间列表筛选出带该标签的条目。
  - 标签右键：编辑标签…、删除标签。
  - 标签区标题右键：新建标签…。

### 4.7 回收站

- **TRASH-01【原始】** 在回收站以外删除的条目或文件都进入回收站，并记录删除时间。
- **TRASH-02【确认】** 自建分组视图中的右键菜单同时提供"从当前分组移除"和"删除"：
  - "从当前分组移除"只解除分组关系，不进回收站。
  - "删除"会移到回收站，条目从所有分组中消失。
  - "所有文献""未分组"和标签视图中只有"删除"。
  - 快捷键：⌘⌫ = 删除；自建分组中 ⌫ = 从当前分组移除，其他视图中 ⌫ = 删除。
- **TRASH-03【细化】** 删除条目时，它下面的所有文件一起进入回收站。单独删除某个文件时，回收站中单独显示这个文件，并附"来自：条目标题"。
- **TRASH-04【原始】** 回收站中的条目或文件右键：恢复、彻底删除（需确认）。
- **TRASH-05【原始】** 恢复规则：
  - 条目回到删除前所属的、目前仍存在的全部分组。这些分组都不存在时，它出现在"所有文献"和"未分组"。
  - 单独删除的文件，恢复到原条目下（原条目存在且未被删除时）；否则作为独立文件出现在"所有文献"和"未分组"。
- **TRASH-06【原始】** 右键回收站可一键清空（需确认）。
- **TRASH-07【补充】** 回收站中超过 30 天的内容自动彻底删除（设置中可关闭）。
- **TRASH-08【原始】** 彻底删除会同时删除文献库中的文件副本、全文索引和所有关联，无法恢复。
- **TRASH-09【细化】** 回收站中的内容不计入其他分组的数量，也不出现在其他视图的搜索结果中。
- **TRASH-10【细化】** 把条目拖到侧栏的"回收站"上等同于删除。

### 4.8 标签

- **TAG-01【原始】** 每个条目（包括独立文件）可以有零个或多个标签。
- **TAG-02【原始】** 添加标签时可以从已有标签中选择，也可以新建。入口有：
  - 右键条目的"标签 ▸"子菜单：列出已有标签，点击切换勾选；底部是"新建标签…"。
  - 【补充】检查器标签行的"+"：弹出标签选择器，可搜索和勾选已有标签；输入的名称不存在时提供"新建标签「xxx」"。
  - 【细化】把条目拖到侧栏的某个标签上。
- **TAG-03【原始】** 新建标签需要填写文字并选择颜色：
  - 颜色有 10 种预设色，也可以自定义颜色。【v2.2】颜色以一排同样大小的圆点显示，最后一个彩虹圆点打开系统颜色面板；选中的颜色外加圆环。
  - 名称不能为空，也不能重复（不区分大小写）。
- **TAG-04【原始】** 可以编辑已有标签（文字、颜色），也可以删除标签。删除前需确认，并说明会从多少个条目中移除。入口：侧栏标签区右键、标签选择器中右键。
- **TAG-05【原始】** 条目上的标签显示为彩色胶囊：
  - 单个标签最大宽度约 6 个汉字（约 90pt），超出部分用"…"截断。
  - 标签列宽度放不下全部标签时，显示"+N"。
  - 鼠标悬停显示完整的标签列表。
- **TAG-06【细化】** 多选条目后可以批量添加或移除标签。
- **TAG-07【细化】** 移除条目上的标签：在"标签 ▸"子菜单中取消勾选，或点击检查器中标签胶囊上的 ×。

### 4.9 搜索

- **SEARCH-01【v2.0 变更】** 搜索框是工具栏右侧的系统搜索框（`NSSearchToolbarItem`）。⌘F、编辑菜单"查找"、侧栏空白处右键"搜索文献"都会聚焦它；按 Esc 清空并结束搜索。
  - 搜索时，列表上方出现系统风格的范围栏（与 Finder 搜索相同）：［当前分组］［全部文献］，以及"包含 PDF 全文"复选框。
- **SEARCH-02【确认】** 边输入边过滤中间列表：
  - 匹配范围：标题、作者、来源、年份、标签名、DOI、arXiv ID、摘要、文件名。
  - 多个关键词之间是"且"的关系，不区分大小写。
- **SEARCH-03【确认】** 搜索范围可在"当前分组"和"全部文献"之间切换。
- **SEARCH-04【补充】** "包含 PDF 全文"开关：打开后同时搜索 PDF 正文，正文由后台建立全文索引。
- **SEARCH-05【细化】** 搜索时，列表标题显示为"「关键词」的搜索结果"。右键、拖到侧栏等操作照常可用，但不能拖拽排序。

### 4.10 拖拽

- **DND-01【原始】** 从 Finder 把文件拖到主界面（中间列表区域）：
  - 出现 Liquid Glass 动画浮层"松开以添加 N 个文件"；松手后浮层消失并开始导入，PDF 自动检索元数据。
  - 【细化】支持同时拖入多个文件。拖入文件夹时，递归导入其中的 PDF。
  - 【确认】当前正在查看自建分组时，新条目同时加入该分组。
- **DND-02【确认】** 从 Finder 把文件拖到侧栏：
  - 拖到某个自建分组：导入并加入该分组。
  - 拖到"所有文献"或"未分组"：只导入。
  - 拖到"回收站"：不允许。
- **DND-03【原始】** 在列表中把条目或独立文件拖到侧栏：
  - 拖到自建分组：加入该分组。这里加入的是同一个条目，不会复制出副本。
  - 拖到当前所在的分组：什么都不做。
  - 目标分组中已有该条目：提示"已有该条目"。
  - 【细化】拖到"回收站"等同删除；拖到标签上会添加该标签；拖到"所有文献"或"未分组"不允许。
- **DND-04【原始】** 在列表内拖拽行可以调整顺序，拖动时有插入线指示。搜索状态下禁用。
- **DND-05【原始】** 分组之间的拖拽见 SIDE-12。
- **DND-06【细化】** 把条目从 Folio 拖到 Finder 或其他 App，得到的是它的默认打开文件；拖出文件行则得到该文件。

### 4.11 检查器（右栏）【补充】

- **INSP-01** 用工具栏按钮或 ⌥⌘I 显示、隐藏检查器，宽度可调。
- **INSP-02** "元数据"页，参照参考图：
  - 字段：类型、标题、作者（可增删、调整顺序）、年份/日期、来源、卷、期、页码、出版社、DOI（可点击打开）、arXiv ID、ISBN、URL（可点击打开）、摘要（可折叠）、引用键、标签（胶囊，可添加或移除）、所属分组（胶囊，可添加或移除）、评分、阅读状态、添加时间和修改时间、文件列表。
  - 文字字段都可以直接编辑，按回车或失去焦点时保存。
- **INSP-03** "标注"页：只读汇总该条目所有 PDF 中的高亮、下划线、删除线、注释、文本框。
  - 每条标注显示颜色、类型、页码、原文、批注内容。
  - 支持搜索，可一键打开对应的 PDF。
- **INSP-04** 选中独立文件时，显示文件名、大小、添加时间，以及"检索元数据""手动匹配…"按钮。
- **INSP-05** 选中文件行时，显示其所属条目的信息。多选时显示"已选择 N 项"。

### 4.12 打开方式【确认】

- **OPEN-04【v2.0】** 条目和文件的右键菜单都有"在 Folio 中阅读""用预览打开""用其他应用打开 ▸"。
- **OPEN-02** 用 Quick Look 快速预览，见 LIST-09。
- **OPEN-03【细化】** 打开"未读"条目时，它的阅读状态自动变为"在读"。

### 4.13 引用导出【补充】

- **CITE-01** 右键"复制引用 ▸"，可选 BibTeX、GB/T 7714-2015、APA 第 7 版。多选时一次复制多条，复制后提示"已复制"。
- **CITE-02** 文件菜单或工具栏导出按钮"导出 BibTeX…"：导出选中项，未选中时导出当前视图的全部条目，保存为 `.bib` 文件。
- **CITE-03** 引用键规则：第一作者姓（小写）加年份，如 `zhang2026`；重复时追加 a、b、c。引用键在检查器中可编辑。

### 4.14 从 Zotero 导入【确认】

- **ZOT-01** 从文件菜单或设置中选择"从 Zotero 导入…"：
  - 自动定位 `~/Zotero`，也可以手动选择数据目录。
  - 读取时复制一份数据库，只读，不修改 Zotero。
- **ZOT-02** 导入的内容：
  - 常规条目及其元数据。
  - 附件：库内存储的文件复制进 Folio 库；链接文件若仍存在也复制。
  - Zotero 的独立附件导入为独立文件。
  - 分组结构：一、二级保持不变；三级及更深分组中的条目并入其所属的二级分组。
  - 标签：有颜色的保留颜色，其余用灰色。
    - 手动标签总是导入。
    - Zotero 自动生成的标签（出版商关键词、arXiv 分类），由导入窗口中的"同时导入自动标签"开关决定，默认关闭。
  - 默认打开文件：条目中最早添加的 PDF。
- **ZOT-03** 跳过：笔记、网页快照、链接网址、Zotero 内置阅读器中的批注（存在 Zotero 数据库里，不在 PDF 文件中），以及 Zotero 回收站中的条目。
- **ZOT-04** 与 Folio 库中已有的内容去重（按文件哈希和 DOI）。
- **ZOT-05** 导入时显示进度；完成后显示摘要：导入了多少条目、文件、分组、标签，跳过了多少重复项。
- **ZOT-06** 导入的条目不重新检索元数据。

### 4.15 阅读状态与评分【补充】

- **READ-01** 阅读状态分为未读、在读、已读，新条目默认"未读"：
  - 可以作为列显示，未读用蓝点表示。
  - 通过右键"阅读状态 ▸"或检查器修改。
- **READ-02** 评分为 1 到 5 星：
  - 可以作为列显示。
  - 在检查器中点击星星设置；再次点击当前星级则清除评分。

### 4.19 内置阅读器【v2.0】

- **READER-01** 双击条目（默认打开文件是 PDF 时）或文件行，在新的原生标签页中打开该 PDF；该文件已经打开时切换到已有标签。⌥ 双击在后台标签打开。
- **READER-02** 阅读器窗口：
  - 左侧栏（可隐藏）：缩略图 / 目录（PDF 大纲）/ 批注列表 / 查找结果四页。
  - 中间是 PDFKit 页面视图；右侧检查器（可隐藏）显示该条目的笔记（见 4.20）。
  - 窗口标题为条目标题，副标题为"第 N / M 页"。
- **READER-03** 浏览：放大 ⌘+、缩小 ⌘−、实际大小 ⌘0、适合页宽、单页连续 / 双页连续、上一页 / 下一页、前往页面…（⌥⌘G）、⌘F 在文档中查找（工具栏搜索框，结果在左侧栏列出，⌘G / ⇧⌘G 跳转）。
- **READER-04** 批注工具（工具栏与"批注"菜单）：选择、高亮、下划线、删除线、便签、文本框、手绘；颜色 6 种预设（黄、绿、蓝、粉、紫、红）。
  - 文字类批注：选中文字后点工具，或先选工具再拖选文字，自动生成。
  - 便签、文本框：选工具后点击页面放置，弹出编辑框输入内容。
  - 手绘：选工具后拖动绘制。
  - 点击已有批注将其选中：可拖动移动位置（便签、文本框、手绘）、按 ⌫ 删除、右键改颜色 / 编辑内容 / 删除。
  - 所有批注操作支持撤销 / 重做（⌘Z / ⇧⌘Z）。
- **READER-05** 批注以标准 PDF 批注写回文件：改动 1 秒后自动保存（原子写入），关闭标签或退出时立即保存。保存后条目的文件指纹、全文索引和检查器"标注"页自动更新。在"预览"中添加的批注在 Folio 中同样可见、可编辑。
- **READER-06** 记住阅读位置：每个文件记住页码、页内位置、缩放和显示方式；重新打开时回到上次的位置。阅读位置单独存储，不触发列表刷新。
- **READER-07** 启动时重新打开上次关闭 App 时打开着的论文标签页（设置中可关闭）。
- **READER-08** 选中文字后右键：拷贝、高亮 / 下划线 / 删除线、添加到笔记（以引用块插入，附页码）、拷贝为引用（附文献引用）。
- **READER-09** 打开"未读"条目时阅读状态自动变为"在读"（沿用 OPEN-03）。
- **READER-10** 有译文时，可以"对照阅读"：原文和译文左右并排，按页同步滚动（见 4.21）。

### 4.21 保留排版的整篇翻译【v2.0】

- **TRANS-01** 条目或 PDF 文件右键"翻译全文…"、阅读器工具栏"翻译"按钮：调用 pdf2zh_next（BabelDOC）把 PDF 翻译成保留原排版、公式和图表的译文 PDF。

  - 设置"翻译"页：选择服务后只显示该服务需要的字段（API Key、模型、Base URL 等），API Key 存入钥匙串。
  - 【v2.4】推理强度与 API Key、模型同级显示，选项随服务和模型变化：GPT-5（最低/低/中/高）、o 系列（低/中/高）、非推理模型不发送；DeepSeek（默认/关闭思考/高/最高）；SiliconFlow（默认/开启/关闭思考）；兼容接口（不设置/低/中/高）。推理模型默认"中"。
  - 【v2.3】模型字段旁有"获取模型列表"按钮：用已填写的 Key 和地址向服务查询可用模型（OpenAI 及兼容接口、DeepSeek、SiliconFlow、阿里云百炼、通义千问 MT、ModelScope、智谱、Groq、Grok、Gemini、Ollama、Xinference），在可搜索的列表中点选即可填入。
  - 通用选项：源语言（默认英语）、目标语言（默认简体中文）、输出（纯译文 / 双语对照 / 两者）、双语排版（左右 / 上下交替页）、页码范围、术语表（可选 CSV）、翻译表格中的文字、兼容模式、QPS。
- **TRANS-04** 翻译在后台进行，最多同时 1 篇，其余排队：列表标题列显示"正在翻译… 35%"，阅读器工具栏显示进度；可在右键菜单"取消翻译"。
- **TRANS-05** 完成后，译文 PDF 作为该条目的新文件加入（命名为"原文件名（中文译文）.pdf""原文件名（双语对照）.pdf"），文件行显示"译文"标识，并记住它对应的原文件；完成时轻提示，可一键打开。
- **TRANS-06** 失败时显示原因（网络、API Key、额度、组件损坏等）和"重试""查看日志"。

### 4.23 浏览器插件【v2.5，v2.6 修订】

- **WEB-01 连接服务**：Folio 运行时在 `127.0.0.1:23120` 提供本地连接服务（只监听本机，校验 Host）。只接受浏览器扩展发来的请求（`chrome-extension://`、`safari-web-extension://`、`moz-extension://` 来源，且带 `X-Folio-Connector` 请求头），网页无法调用。设置中可关闭。
- **WEB-02 识别**：点击工具栏按钮时读取当前页面的文献信息：Highwire `citation_*`、Dublin Core、PRISM、COinS、JSON-LD（ScholarlyArticle）、Open Graph，按字段优先级取值；网址和页面中的 DOI、arXiv 编号；ScienceDirect、IEEE Xplore 等站点规则；当前页是 PDF 时保存该 PDF（页面无法读取时按网址判断）。只在点击时读取，不常驻页面。【v2.6】
- **WEB-03 弹出窗口**（macOS 风格，跟随浅色 / 深色）：
  - 显示识别到的类型、标题、作者、年份、来源；没识别到时可"保存为网页"。
  - 分组选择：列出 Folio 的全部分组（子分组缩进），默认 Folio 当前正在查看的分组，其次是上次的选择；可选"不放入分组"。
  - 标签（逗号分隔，可从已有标签中补全）；"同时保存 PDF"（页面提供 PDF 时）。
  - 保存后显示"已保存到「分组」"或"文献库中已有"，并可"在 Folio 中显示"（不打开新标签页）；同时保存 PDF 时显示下载进度和结果（已附加 / 需要登录或订阅 / 不是 PDF）。【v2.6】
  - **批量保存**【v2.6】：搜索结果、arXiv 列表等包含多篇文献的页面，列出页面中的 DOI / arXiv 文献供勾选，按标识符检索完整信息后一次保存到所选分组。
  - Folio 未运行时提示并提供"打开 Folio"；扩展版本与 Folio 不一致时提示重新安装。
- **WEB-04 保存**：有 DOI / arXiv / ISBN 时用 Folio 的检索引擎取完整元数据（与页面信息合并），否则用页面信息；与已有条目去重（已有时加入所选分组）；PDF 由浏览器下载（可带登录状态，自动跟随出版社的中转页）后交给 Folio 附加到条目，成功或失败都在 Folio 中提示。

  - Safari：扩展随 Folio.app 提供。设置 ▸ 浏览器 中分步说明：因 Folio 使用开发证书签名，需先在 Safari 设置 ▸ 高级 打开"显示网页开发者功能"，再在 开发者 中勾选"允许未签名的扩展"（每次重新打开 Safari 后需再次勾选），然后在 扩展 中勾选 Folio；实时显示是否已启用。

- **WEB-06 右键菜单与快捷键**【v2.6】：页面右键"保存到 Folio"打开弹窗；链接右键"保存链接到 Folio"（PDF 链接直接导入，DOI / arXiv 链接按标识符保存到 Folio 当前分组）；快捷键打开弹窗（Chrome 默认 ⌘⇧S，可在浏览器中修改）。

## 5. 不在本期范围

- 多设备或云同步
- Word / WPS 引用插件；浏览器插件上架各应用商店
