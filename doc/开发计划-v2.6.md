# Folio v2.6 开发计划：浏览器插件、MCP 与技能的深度优化

> 依据：`doc/需求文档.md` v2.6（4.22 AI 接入、4.23 浏览器插件）。用户反馈：插件难以正确安装、识别不到或识别错；智能体无法正确连接 Folio 的 MCP 和技能，要求逐个核实主流智能体的官方安装方式。
>
> 用户确认（2026-10-13）：插件保持"先选分组再保存"；AI 与 App 都增加 IEEE、MLA、Chicago、Harvard、Vancouver、Nature 引用格式，AI 可生成文中引用；插件新增"批量保存列表页"；知网 / 万方不在本期。
>
> 执行方式：主 agent 在 `main` 上按下列顺序完成，每一步编译、测试通过后提交（Conventional Commits）。

## 三、任务

### 阶段 1 引用格式（FolioCitation + App）
1. 内置 IEEE、MLA 第 9 版、Chicago 第 18 版（作者-日期）、Harvard（Cite Them Right）、Vancouver（NLM）、Nature 的 CSL 文件（官方仓库，CC BY-SA 3.0），登记到 LICENSES.md。
2. `CitationStyle` 增加以上格式；`CSLRenderer` 按需加载样式；所有 citeproc 样式都输出 HTML（保留斜体）。
3. 新增文中引用：`CSLRenderer.inTextCitations` 返回每条的文中引用和合并引用（如 "(Wang et al., 2025; Tan et al., 2021)" / "[1], [2]"）。
4. App 的"拷贝引用"菜单与工具栏菜单列出全部格式；测试。

### 阶段 2 MCP 服务器（FolioAgent/MCP*）
1. 传输层：按字节读取 stdin，只以 `\n` 分行（容忍 `\r\n`）；协议输出写到复制出的原 stdout 句柄，fd 1 重定向到 stderr，防止任何 print 污染协议；输出中的 U+2028 / U+2029 转义。
2. 并发：每个请求一个 Task，输出经 actor 串行写出；支持 `notifications/cancelled`。
3. 双时代协议：旧版 `initialize`（2025-11-25 / 06-18 / 03-26 / 2024-11-05）；新版每个请求 `_meta` 中的版本、`server/discover`、`UnsupportedProtocolVersionError (-32022)`、结果带 `resultType` 与 `serverInfo`，列表结果带 `ttlMs` / `cacheScope: "private"`。
4. 错误：未知工具 → JSON-RPC -32602；参数校验（未知参数名、缺必填、类型）→ `isError` 并说明可用参数，便于模型自我纠正。
5. 输出：紧凑 JSON，去掉 null / 空数组 / 空字符串，不再重复 `structuredContent`。
6. 每次调用重新读取"允许 AI 修改"与文献库位置；旧版会话中开关变化时发送 `notifications/tools/list_changed`。
7. 文献库打不开时仍完成握手，工具调用返回可读的原因。
8. 提示词（prompts）：`find_paper`、`cite_papers`、`summarize_paper`，在 Claude Code 等中显示为斜杠命令。

### 阶段 3 工具（LibraryToolbox / ToolCatalog）
1. `search_library`：过滤 `author`、`year_from`、`year_to`、`item_type`、`read_status`、`tags`；只有过滤条件时可不填关键词；排序按词首匹配、整句匹配、作者姓氏加权；全文命中返回片段（FTS5 snippet）；可选 `include_abstract`。
2. `list_items`：同样的过滤条件与 `sort`（added / year / title / rating）。
3. `read_fulltext`：新增 `query`，只返回论文中匹配的段落及页码；修正页码范围的边界情况。
4. `format_citations`：全部 9 种格式；`mode`：`bibliography`（默认）/ `in_text` / `both`。
5. `add_item_by_identifier`：`download_pdf`（arXiv 直接下载；DOI 经 OpenAlex 找开放获取 PDF）。
6. `add_pdf`：支持 `url`。新增 `attach_file`：给已有条目附加本地文件或网址上的 PDF。
7. 新增 `folio-cli status`（文献库位置、条目数、是否允许修改、版本），便于技能和用户排查。

### 阶段 4 技能（FolioSkill）
1. 改为技能文件夹：`SKILL.md`（精简，<200 行）+ `references/tools.md`（由 ToolCatalog 自动生成，永不脱节）+ `references/cli.md` + `references/writing.md`（写 LaTeX / Markdown / Word 时如何引用与导出 .bib）。
2. frontmatter：`name`、`description`（≤1024 字符，含中文触发词）、`allowed-tools`（只读工具）。
3. 安装时整个文件夹写入；识别标记仍在 SKILL.md。

### 阶段 5 智能体配置（AgentIntegrations + 设置 ▸ AI）
1. JSONC 精确编辑器：只改动 Folio 自己的条目，保留其余内容、键的顺序、缩进与注释；可解析注释和结尾逗号。
2. 按第二节更新目录：新增 Copilot CLI、Zed、Qwen Code；Antigravity / Windsurf / Cline 新路径；opencode `.jsonc`。
3. 技能按"读取目录 + 首选目录"建模，状态从所有读取目录判断；迁移：删除 Folio 旧装在 `~/.codex/skills`、`~/.gemini/antigravity/skills` 的副本并装到正确位置。
4. 设置页：每个智能体显示 MCP 与技能开关、配置文件位置（可在 Finder 中显示）；共享技能的说明与关闭确认；"检查 MCP 服务器"按钮（实际启动 folio-cli 握手并列出工具数与文献库）。

### 阶段 6 浏览器插件
1. 识别（extract.js）：按优先级取值；检查全部标识符字段；COinS；页面中的 DOI 链接（唯一或位于标题区）；ScienceDirect、ACM 等站点规则；无法读取页面时按网址判断 PDF。
2. 批量保存：页面没有单篇文献、但有多个 DOI / arXiv 链接时，弹窗列出可勾选的条目（标题取自链接附近），按标识符批量保存（`/saveItems`）。
3. PDF：后台下载并识别中转页（meta refresh、脚本跳转、iframe / embed、PDF 链接）；弹窗显示下载进度与结果（已附加 / 需要登录 / 不是 PDF），Folio 中提示。
4. 弹窗："在 Folio 中显示"改由连接服务 `/reveal` 完成；"打开 Folio"不再留下空白标签页；扩展版本与 Folio 不一致时提示重新安装。
5. 右键菜单："保存到 Folio"（页面）、"保存链接到 Folio"（PDF 链接导入、DOI / arXiv 链接按标识符保存）；快捷键 ⌘⇧S（Chrome）/ 可在浏览器中修改。
6. 连接服务：校验 Host；新增 `/reveal`、`/saveItems`、`/status`；PDF 附加成功或失败都在 Folio 中提示。
7. 安装：manifest 加 `key`，扩展 ID 固定；设置 ▸ 浏览器 改为分步安装引导（打开扩展页、开发者模式、加载已解压、⌘⇧G 粘贴路径），按扩展 ID 实时检测是否已安装、已启用；Safari 引导包含"允许未签名的扩展"并实时检测启用状态；`script/package-extensions.sh` 生成 Chrome 商店 .zip 与 Firefox .xpi。
